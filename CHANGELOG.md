## [1.0.0] - 2025-08-16
### Added
- Initial public release of **SteamOS Shell** 🎉
- Replaces Windows Explorer shell with **Steam Big Picture** on login.
- Automatic logout (~10s) after Steam exits.
- Installer automatically creates a **Start Menu folder** (no checkbox needed).
- Installer “Ready to Install” page now displays the chosen **Steam folder**.
- Full uninstall support via **Settings → Apps** or the Start Menu folder.
